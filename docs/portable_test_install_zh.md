# Valewake v1.1.0 安装与验证

包含对话、礼物记录、到点约会/主动走近/跟随恢复及任务功能。内部 manifest 与 Mod 程序版本统一为 1.1.0。此文包含实机验证清单，不代表所有地图已验证。当前发行包面向 Windows，macOS/Linux 未完成适配。

## 安装

从 v1.0 升级请先阅读 UPGRADE_zh.md：关闭游戏、将旧目录移出 Mods，解压新包后双击 Upgrade-Valewake.cmd 选择旧目录。只迁移私人数据与模型设置，不覆盖新版知识。新包不要在迁移前先运行产生另一套记忆。

1. 使用已安装 SMAPI 的 Windows 版《星露谷物语》。关闭游戏及旧 Valewake 后端。
2. 如已有 Valewake，把旧目录先移到 Mods 之外备份。不要只改成 Mods/Valewake-old，SMAPI 仍可能加载它。完整替换能避免旧后端和旧配置残留。
3. 解压后，把整个 Valewake 文件夹放入目标电脑的 Stardew Valley/Mods，确认是 Mods/Valewake/manifest.json，避免多套一层目录。
4. 本包不含 API Key、个人 Memory、对话日志或存档。在 Valewake/config.json 的 LlmApiKey 填自己的 Key，并核对 LlmProvider、LlmModel、LlmApiBase 是否与自己的服务一致。不要在 .env 和 config.json 同时填写不同配置。已有配置建议只迁移必要的服务设置，不覆盖整份新配置。
5. 从 SMAPI 启动游戏。AutoStartBackend 已启用，无需装 Python、手动启动终端服务或修改电脑盘符路径。首次启动等待后端就绪，再加载存档测试。

首次使用新电脑的测试数据为空；要复现原来的关系/剧情条件，需另外转移游戏存档。本包不会自动转移旧电脑的独立 AI Memory。

Generic Mod Config Menu 可选。测试时关闭 ValleyTalk 等同类 NPC 对话接管模组，避免冲突。

自定义扩展 NPC：加载存档后输入 agent_npcs 获取内部名，复制 data/custom_npcs/_template 为自己的目录并启用。人格和知识加载需要重启，详见包内 CUSTOM_NPCS_zh.md。升级时单独保留自己的 custom_npcs 子目录。

## 本轮重点

- 返程补丁：确认结束约会并关闭告别台词后，NPC 按当前日程离开；晚上通常回家，而不是回到约会前旧站位。
- 农场边界出口、多个出口候选、人物挡路与返程重试已调整。不要站在 NPC 脚下或堵住唯一通道；阻塞提示出现时让出一点空间。

- 约会普通跟随速度默认上限 4，远距离追赶上限 5；站定优先正面或侧面。
- 聊天静止不算寻路卡住，关闭聊天后先恢复步行，再按真实导航时间决定是否 TP。
- 约会中或结束后的返程中请求下矿，确认后会把控制权移交给矿洞任务；选 No 不改变当前安排。
- 不再追加固定的“那就今天……确认后我按这个安排来”尾句。测试“八点有点晚了，晚上七点吧”，确认菜单应显示 19:00，而不是 20:00。

- 约会改地点、改时间后只回复“好啊好啊”，也应生成确认提案；先关闭 NPC 回复框再看 Yes/No 确认。未点 Yes 不建立任务。
- “矿洞下面的河边”“罗宾的店门口”解析到山地公开地图；不代表精确定位某扇门。矿洞或商店内部仍不支持。
- 地点不可用时用自然台词重新协商，不再出现“先答应＋括号状态说明”。
- 更新后重新触发一段原版剧情，再问 NPC 刚才说过什么。仅采集实际打开过的 DialogueBox 台词页及已选回答，旧剧情不追溯补录。

- 下午约“六点森林见”应显示 18:00；当天至少提前 30 游戏分钟。
- 已移除提前 20 分钟出发；约定时间之前不控制 NPC 移动。
- 到点后，NPC 已在约定地图则原地等待，玩家走到 12 格内会主动走近并同行，无需再聊一句。
- NPC 不在约定地图时，只在来源和会面落点都无人观察的条件下安全转移。落点被观察时可能等待并迟到。
- 跟随拉开到 16 格、持续卡住约 3 秒、跨地图掉队约 1.5 秒时，尝试传送到玩家可达的附近安全格；没有安全格就等待，不落水、不占玩家脚下或出口。
- 结束约会后检查返程。特殊动态桥梁、改图与联机仍需实机验证。
- 查看 Mods/Valewake/data/traces/meeting_trace.jsonl 与 SMAPI 日志定位问题。

自动验证不等于实机地图验证，发现卡路请保留 NPC 名称、游戏时间、地图、画面及对应 Trace。

## 安全软件拦截

包内 Backend/ValewakeBackend.exe 是 PyInstaller 打包的 Python 后端。若安全软件隔离该文件，SMAPI 会报无法启动或找不到后端。不要直接关闭系统防护；先查看保护历史和具体检测结果、核对来源与文件哈希。不认可来源时不要运行。游戏内容损坏提示是另一类问题，不能仅凭本模组后端缺失作判断。
